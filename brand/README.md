# Brand assets

Official Hantex Ultra assets, extracted from the vector artwork in the brand
guidelines (2026). Do not edit the geometry or colours — see
[`docs/brand-guidelines.md`](../docs/brand-guidelines.md).

| File | Use |
|------|-----|
| `logo/mark-on-dark.svg` | Icon mark on Graphite or other dark grounds |
| `logo/mark-on-light.svg` | Icon mark on Ice, white or other light grounds |
| `logo/mark-mono-light.svg` | Single-colour (Ice) mark on teal, photos or dark grounds |
| `logo/mark-mono-dark.svg` | Single-colour (Graphite) mark on light grounds |

The full lockup (mark + wordmark) follows once the typeface is confirmed.

# Hantex Ultra

Website platform for [Hantex Ultra](https://www.hantexultra.com), a brand
specialising in electrical switches, sockets, lighting, lamps and related
accessories. One dashboard manages Hantex Ultra and any other website the
owner creates.

The project is in **Phase 2: Coming Soon page and dashboard foundation**. The
plan was updated on 2026-10-21 for multiple websites, a product-focused
catalogue, a reusable design system and the AI 3D Product Studio.

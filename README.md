# Hantex Ultra

Website platform for [Hantex Ultra](https://www.hantexultra.com), a brand
specialising in electrical switches, sockets, lighting, lamps and related
accessories. One dashboard manages Hantex Ultra and any other website the
owner creates.

Phase 2 (Coming Soon page and multi-site dashboard foundation) is built and
was approved by the owner on 2026-10-21. The first deployment is being
prepared; nothing is live yet. Next: Phase 3 (media, product catalogue and the
3D Studio foundation).
